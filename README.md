# Knowledge Base

Персональная база знаний, построенная на подходе **LLM Wiki** от Andrej Karpathy.

## Архитектура

```
Sources (исходники)
    ↓
Wiki (управляемые LLM markdown-файлы с перекрестными ссылками)
    ↓
Schema (конфигурация структуры и рабочих процессов)
```

## Основные операции

### 1. **Ingestion** (Поглощение)
- Обработка новых источников (статьи, исследования, заметки)
- Автоматическое обновление связанных страниц в wiki
- Добавление новых ссылок и ассоциаций

### 2. **Query** (Запрос)
- Синтез ответов на основе уже скомпилированного знания в wiki
- Не требует переиндексирования при каждом запросе
- Быстрые, актуальные результаты

### 3. **Lint** (Проверка)
- Выявление противоречий в информации
- Проверка консистентности ссылок
- Выявление пропусков и недостающих связей

## Структура папок

```
Knowledge_base/
├── README.md
├── schema.md (конфигурация и структура)
├── sources/ (исходные неизменяемые документы)
│   └── article_name.md
├── wiki/ (управляемые wiki-страницы)
│   ├── concepts/
│   ├── techniques/
│   ├── projects/
│   └── index.md
└── logs/ (история ingestion и обновлений)
```

## Преимущества подхода

✓ Один раз скомпилированное знание (не переиндексируется)  
✓ LLM выполняет рутину (обновление ссылок, выявление противоречий)  
✓ Человек сосредоточен на куратстве и анализе  
✓ Персональная ассоциативная структура (как memex от Vannevar Bush)
