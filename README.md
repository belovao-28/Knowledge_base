# Knowledge Base

Персональная база знаний, построенная на подходе **LLM Wiki** от Andrej Karpathy.

## 🎯 Главная концепция

Вместо традиционного RAG-подхода ("переиндексирование при каждом запросе"), база знаний **один раз компилируется, а затем поддерживается** как живая вики-система с перекрестными ссылками.

## 📋 Архитектура

```
Sources (исходные материалы, статьи)
    ↓
Wiki (управляемые LLM markdown с ссылками)
    ↓
Schema (конфигурация и структура)
```

## 🔄 Основные операции

### 1. **Ingestion** (Поглощение)
- Обработка новых источников (статьи, исследования, заметки, встречи)
- Проверка на дубликаты и интеграция в существующие документы
- Добавление перекрестных ссылок (минимум 3)
- Обновление индексов

### 2. **Query** (Запрос)
- Синтез ответов из уже скомпилированного знания в wiki
- Не требует переиндексирования при каждом запросе
- Быстрые, актуальные результаты с цитатами источников

### 3. **Lint** (Проверка)
- Выявление противоречий в информации
- Проверка консистентности ссылок
- Выявление пропусков и изолированных документов
- Архивация устаревшего контента

## ✨ Преимущества подхода

✓ Один раз скомпилированное знание (не переиндексируется)  
✓ LLM выполняет рутину (обновление ссылок, выявление противоречий)  
✓ Человек сосредоточен на куратстве и анализе  
✓ Персональная ассоциативная структура (как memex от Vannevar Bush)  
✓ Цитаты из первоисточников — защита от галлюцинаций  
✓ Структурированные шаблоны для быстрого добавления контента  

## 🚀 Как начать

1. **Прочитай правила:** [[KNOWLEDGE_BASE_RULES.md](KNOWLEDGE_BASE_RULES.md)]
2. **Выбери раздел:** [[wiki/index.md](wiki/index.md)]
3. **Скидывай контент:** статьи, встречи, идеи, проекты
4. **Я обработаю:** создам или обновлю документы согласно правилам

### Быстрая команда
```
Обработай эти новые данные согласно KNOWLEDGE_BASE_RULES.md
```
