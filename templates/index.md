# Шаблоны для повторяющихся задач

Здесь находятся шаблоны для быстрого создания новых документов в базе знаний.

## Доступные шаблоны

### [[meeting_summary.md]] — Резюме встреч
Для записи итогов встреч, обсуждений и принятых решений.

### [[project_summary.md]] — Описание проекта
Полный шаблон для описания проекта (кейса) с результатами и уроками.

### [[idea_description.md]] — Описание идеи
Для документирования бизнес-идей и инициатив.

### [[roadmap_template.md]] — Дорожная карта
Шаблон для создания стратегических дорожных карт.

### [[problem_solution.md]] — Проблема и решение
Для записи проблем, с которыми столкнулись, и их решений.

### [[technique_guide.md]] — Описание техники
Шаблон для документирования методик и подходов, которые сработали.

## Как использовать шаблоны

1. Скопируй содержимое нужного шаблона
2. Создай новый файл в нужной папке
3. Заполни все разделы согласно шаблону
4. Добавь перекрестные ссылки
5. Обнови индексы

## Правило об обязательности шаблонов

Если пользователь просит:
- "дай саммри встречи" → используй `meeting_summary.md`
- "опиши проект" → используй `project_summary.md`
- "создай план" → используй `roadmap_template.md`
- "какая проблема и решение?" → используй `problem_solution.md`

**Формируй ответ СТРОГО по структуре шаблона.**
