# Knowledge Base Schema

Конфигурация структуры, типов контента и рабочих процессов.

## Типы страниц в Wiki

### 1. Concept (Понятие)
**Путь:** `wiki/concepts/`

Фундаментальные идеи, определения, теории.

```markdown
# [Название концепции]

## Определение
[Краткое определение]

## Суть
[Детальное объяснение]

## Примеры
[Примеры применения]

## Связанные идеи
- [[Концепция 1]]
- [[Концепция 2]]

## Источники
- [Статья 1](link)
```

### 2. Technique (Техника/Методология)
**Путь:** `wiki/techniques/`

Практические методы, алгоритмы, инструменты.

```markdown
# [Название техники]

## Когда использовать
[Контекст и условия применения]

## Шаги
1. [Шаг 1]
2. [Шаг 2]

## Примеры
[Практические примеры]

## Ограничения
[Когда не подходит]

## Связанные техники
- [[Техника 1]]
```

### 3. Project (Проект)
**Путь:** `wiki/projects/`

Описание завершённых или текущих проектов.

```markdown
# [Название проекта]

## Контекст
[Задача и цель]

## Подход
[Используемые концепции и техники]

## Результаты
[Метрики и выводы]

## Уроки
[Чему научились]

## Связанные проекты
- [[Проект 1]]
```

## Метаданные страницы

Каждая страница вики должна иметь в начале:

```yaml
---
title: Название страницы
type: concept|technique|project
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: [tag1, tag2, tag3]
status: draft|published|archived
---
```

## Соглашение о ссылках

- **Внутренние ссылки:** `[[Название страницы]]`
- **Внешние ссылки:** `[Текст](URL)`
- **Ссылки на источники:** `@source-name`

## Процесс Ingestion

1. Добавить исходный документ в `sources/`
2. LLM анализирует содержание
3. Обновляются или создаются связанные вики-страницы
4. Добавляются перекрестные ссылки
5. Запись в `logs/ingestion.log`

## Процесс Query

1. Пользователь задаёт вопрос
2. LLM использует существующие вики-страницы
3. Синтезирует ответ из скомпилированного знания
4. Возвращает с цитатами из wiki

## Процесс Lint

Проверки для выполнения:
- [ ] Все [[ссылки]] указывают на существующие страницы
- [ ] Нет противоречивых определений одного понятия
- [ ] Все источники в `sources/` упомянуты в wiki
- [ ] Нет изолированных страниц (каждая имеет связи)
- [ ] Метаданные заполнены корректно

## Категории тегов

**Domain:** pm, ai, engineering, design, business, psychology  
**Level:** concept, skill, pattern, anti-pattern  
**Status:** todo, in-progress, done  

Пример: `#pm #concept #done`
